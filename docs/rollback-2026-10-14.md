## What changed

| Area | Change |
|---|---|
| Welcome mail | Keeps the List-Unsubscribe + one-click (List-Unsubscribe-Post) headers, like the newsletter (`_shared/welcome-send.ts`). |
| Unsubscribe link | Footer links in the welcome and newsletter go to `https://www.dailymattr.com/unsubscribe` (website page, Dailymattrmain) instead of the supabase.co function URL (`_shared/privacy.ts`, override with secret `UNSUB_LINK_BASE`). The one-click header keeps the function URL. |
| Old links | The unsubscribe function also accepts tokens signed with the retired key in secret `UNSUB_LEGACY_SECRETS` (the 2026-10-13 welcomes were signed with it). |
| Not-a-subscriber | A valid link for an address that is not a subscriber now puts it on the never-send list and succeeds (`can_resubscribe: false`, so the page hides "Resubscribe"). |
| Sending speed | Newsletter drain 500 -> 60 per minute, welcomes 200 -> 40 per 10-minute run (`20261014_slower_sending.sql`). |

# Rolling back the 2026-10-13 changes

Before these changes the code was git commit `f215372`. Everything below was
made live on 2026-10-13.

## What changed

| Area | Change |
|---|---|
| Pre-check | Only `@gmail.com` accepted (`ALLOWED_EMAIL_DOMAINS`, default `gmail.com`); single exceptions the owner names go in the `ALLOWED_EMAIL_ADDRESSES` secret. Randomly typed, shared mailboxes, impossible Gmail names rejected. Rejects go to the never-send list with a status. |
| Never-send list | New statuses: `precheck_domain`, `precheck_validity`, `ses_auto_validation`, `ses_medium_confidence`, `ses_low_confidence` (`20261013_never_send_status.sql` + `_fix.sql`). |
| Welcome sender | Paced to ~10/s, no Brevo fallback, labels SES-blocked addresses (medium/low), emails a welcome report when a batch finishes. |
| Reports | `stats-report` (daily + welcome) and `never-send-report` functions; `email_report_stats()` SQL; cron `shortly-daily-report` 11:35 IST; secret `REPORT_EMAIL_TO`. |
| SES (console) | Auto Validation threshold changed from SES managed to HIGH. |
| Data | 321 non-gmail subscribers deleted (backup: `../reports/backup-non-gmail-subscribers-2026-10-13.json`) and put on never-send; 24 August hard bounces removed; 38 never-delivered addresses held, SES-validated HIGH, released. |
